# Power BI

Place the final PBIX file in this folder if all embedded data are public, synthetic, or otherwise safe to publish.

Suggested file name:

`healthcare_sustainability_case.pbix`

Before publishing, confirm that the PBIX contains no confidential healthcare, employee, patient, facility-security, financial, or proprietary information.

The report should clearly distinguish:

- Public-source values
- Calculated values
- Modeled assumptions
- Scenario outputs
