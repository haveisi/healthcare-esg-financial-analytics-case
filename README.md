# Healthcare Sustainability & Financial Analytics Case

An independent analytics case using publicly available information from
Marshfield Clinic to explore how sustainability, community impact, operational
performance, and financial decision-making can be connected in one reporting
workflow.
> This is an independent portfolio case study. It was not commissioned,
> sponsored, reviewed, or endorsed by Marshfield Clinic or Sanford Health.
> Publicly available information is used for analytical demonstration.
> Financial scenarios are illustrative unless otherwise noted.
